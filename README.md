# SciCode Nexus 🧪

เว็บเพื่อการศึกษา สำหรับนักเรียน มัธยมต้น-ปลาย ใช้เรียนฟิสิกส์ เคมี ชีววิทยา และคณิตศาสตร์ ผ่านเครื่องคิดเลขสูตรอัตโนมัติ + สรุปเนื้อหาหลักสูตร

## ✨ ความสามารถหลัก

- **เครื่องคิดเลขสูตร (Formula Solver)** — เลือกสูตร เลือกตัวแปรเป้าหมาย พิมพ์ค่าที่รู้ แล้วระบบคำนวณหาค่าที่ต้องการให้ พร้อมแสดงวิธีทำทีละขั้นตอน (LaTeX + KaTeX)
  - ฟิสิกส์: การเคลื่อนที่, แรง, โมเมนตัม, ความโน้มถ่วง, วงจรไฟฟ้า, คลื่น, อุณหพลศาสตร์, แสง
  - เคมี: สะพานโมล, ความเข้มข้น, pH, การเจือจาง, แก๊สอุดมคติ
  - ชีววิทยา: ฮาร์ดี-ไวน์เบิร์ก, การเจริญแบบเอกซ์โปเนนเชียล, ประชากร
  - คณิตศาสตร์: พีชคณิต, แคลคูลัส, เรขาคณิต, สถิติ
- **บทเรียนตามหลักสูตร (Curriculum)** — ค้นหาและเปิดอ่านบทเรียนทีละบท ตามระดับชั้นและรายวิชา
- **ห้องเรียนโค้ด (Coding Lab)** — เรียนรู้การเขียนโปรแกรมเชื่อมโยงกับเนื้อหาวิชา
- **ตู้สูตรและแผนที่เรียน (Vault)** — สรุปสูตรยอดฮิต + Roadmap การสอบเข้ามหาวิทยาลัย

## 🚀 วิธีรันในเครื่อง

ไม่มี dependency ต้องการ HTTP server เท่านั้น (ใช้ ES Modules ห้ามเปิดผ่าน `file://`):

### Windows (PowerShell)
```powershell
powershell -ExecutionPolicy Bypass -File .\server.ps1
```
หรือดับเบิลคลิก `start.bat` → เปิดที่ `http://localhost:3000/`

### Manual
เปิดไฟล์ด้วยภาษาใดก็ได้ที่ serve static ได้ เช่น:
```bash
python -m http.server 3000
```

## 🗂 โครงสร้าง

```
index.html                     # หน้าเว็บเดียว (SPA)
css/styles.css                 # สไตล์หลัก
js/
├── app.js                     # ตัวควบคุมหลัก (tabs, navigation)
├── data/
│   ├── formulas.js            # ข้อมูลสูตรทั้งหมด
│   ├── lessons.js             # บทเรียนโค้ด
│   ├── resources.js           # ตู้สูตร + Roadmap
│   └── curriculum/            # เนื้อหาหลักสูตรแยกตามวิชา
├── engine/
│   ├── solver.js              # แก้สมการ ทีละขั้นตอน
│   ├── codeRunner.js          # รันโค้ด Luau จำลอง
│   └── visualizer.js          # ภาพประกอบ
└── ui/                        # ส่วนติดต่อผู้ใช้ (tabs, toast, ฯลฯ)
```
